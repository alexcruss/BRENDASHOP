# BrendaSTYLE — Tissus & press-on nails

Site vitrine réalisé pour **BrendaSTYLE**, boutique de tissus wax, satin et press-on nails à Adidogomé (Lomé, Togo). TikTok : [@brendastyle02](https://www.tiktok.com/@brendastyle02).

**En ligne : [alexcruss.github.io/BRENDASHOP](https://alexcruss.github.io/BRENDASHOP/)**

## Ce que fait le site

- Présente la boutique, ses tissus et ses press-on nails
- Sélection de produits filtrable (tissus, press-on nails)
- Commande par WhatsApp : les articles choisis s'ajoutent à « Ma commande », puis un message prérempli part sur WhatsApp. Chaque article a aussi un bouton « Demander le prix »

## À compléter avec Brenda

Le catalogue (noms de produits) est un exemple, et les prix ne sont pas affichés. Quand elle les confirme, les ajouter dans les cartes `.prod-card` de `index.html`. Le numéro WhatsApp (+228 93 15 03 89) vient de sa bio TikTok.

## Technique

Site statique, un seul `index.html` (CSS et JS en ligne), responsive, hébergé sur GitHub Pages. Les images optimisées sont dans `images/web/` ; les originaux sont dans `images/`.
